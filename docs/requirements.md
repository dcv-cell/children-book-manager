
# 儿童绘本二手书管理小程序 - 需求文档

## 1. 项目概述
个人使用的儿童绘本二手书管理工具，无需公开发布，支持局域网/内网穿透访问。

## 2. 功能需求

### 2.1 图书录入模块
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| ISBN 扫描 | 使用小程序扫码功能扫描图书背面 ISBN 条码，自动获取图书信息 | P0 |
| 信息自动填充 | 自动填充：书名、作者、出版社、定价、适合年龄、封面图 | P0 |
| 手动编辑 | 支持手动补充/修改所有图书信息 | P1 |
| 实物拍照 | 支持拍摄图书实物照片（正面/封底/内页，最多 5 张） | P1 |
| 自动去重 | 扫描已录入的 ISBN 时提示已存在 | P1 |

### 2.2 图书管理模块
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 图书列表 | 展示所有图书，支持按状态/年龄/主题筛选 | P0 |
| 自动归类 | 按适合年龄（0-2岁/3-6岁/7-10岁）、主题标签自动分类 | P1 |
| 存放位置 | 管理图书存放位置（如：书架 A-3、收纳箱 2） | P0 |
| 状态管理 | 三种状态：待售、已售、自留 | P0 |
| 售价设置 | 自定义售价，支持基于定价设置折扣（如：5折、3折） | P0 |
| 图书详情 | 查看完整图书信息和实物照片 | P0 |
| 编辑/删除 | 支持编辑图书信息和删除图书 | P1 |

### 2.3 分享选书模块
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 生成分享链接 | 生成选书页面链接，支持设置有效期（如：7天）和访问密码 | P0 |
| 选书页面 | 展示待售图书，支持按年龄/价格/主题筛选 | P0 |
| 购物车 | 支持将图书加入购物车，自动计算总价 | P0 |
| 导出清单 | 支持导出选书清单（文本/图片格式） | P1 |
| 库存同步 | 选书后自动锁定库存，避免超卖 | P1 |

### 2.4 闲鱼对接模块（半自动）
| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 生成发布文案 | 一键生成闲鱼发布文案（包含书名、作者、适合年龄、售价、实物图） | P1 |
| 图片拼图 | 自动将图书封面和实物照片拼成适合闲鱼的长图 | P1 |
| 链接记录 | 记录闲鱼商品链接，同步库存状态 | P1 |
| 订单录入 | 支持手动录入订单信息，或通过截图 OCR 识别 | P2 |

## 3. 非功能需求
- **性能**：图书列表加载时间 &lt; 2s（1000 本以内）
- **可用性**：个人使用，支持局域网访问，可选外网穿透
- **成本**：尽量使用免费服务，总成本 &lt; 10 元/月
- **易用性**：界面简洁，操作流程简单，适合非技术用户

## 4. 数据模型
### 4.1 图书表 (books)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| isbn | TEXT | ISBN 编号，唯一 |
| title | TEXT | 书名 |
| author | TEXT | 作者 |
| publisher | TEXT | 出版社 |
| price | REAL | 定价 |
| selling_price | REAL | 售价 |
| age_range | TEXT | 适合年龄（如：3-6岁） |
| tags | TEXT | 主题标签，逗号分隔 |
| cover_url | TEXT | 封面图 URL |
| photos | TEXT | 实物照片路径，JSON 数组 |
| location | TEXT | 存放位置 |
| status | TEXT | 状态（available/sold/kept） |
| created_at | TEXT | 创建时间 |
| updated_at | TEXT | 更新时间 |

### 4.2 分享链接表 (share_links)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| code | TEXT | 分享码，唯一 |
| password | TEXT | 访问密码（可选） |
| expires_at | TEXT | 过期时间 |
| created_at | TEXT | 创建时间 |

### 4.3 购物车表 (carts)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| share_link_id | INTEGER | 关联分享链接 ID |
| book_id | INTEGER | 关联图书 ID |
| created_at | TEXT | 创建时间 |
